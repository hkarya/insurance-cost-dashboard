# 🏥 Insurance Cost Analysis Dashboard

An interactive data analytics dashboard that explores medical insurance charges and identifies relationships between insurance costs and factors such as age, BMI, smoking status, gender, number of children, and geographical region.

🔗 **Live Dashboard:** https://hkarya.github.io/insurance-cost-dashboard/

📂 **GitHub Repository:** https://github.com/hkarya/Insurance-Cost-Prediction-project.

---

## 📌 Project Overview

The objective of this project is to analyze medical insurance data, identify important factors influencing insurance charges, and present meaningful insights through an interactive dashboard.

The dashboard helps users explore insurance cost patterns, compare different customer segments, and understand relationships between demographic and lifestyle factors and insurance expenses.

## 🎯 Business Problem

Insurance companies need to understand the factors that influence medical insurance costs.

This project explores questions such as:

- How does age influence insurance charges?
- Do smokers have higher insurance costs than non-smokers?
- Is BMI associated with higher insurance charges?
- How do insurance charges vary across different regions?
- Are there meaningful differences in charges across gender and family size?

## 📊 Dataset Description

The project uses a medical insurance dataset containing 1,338 records and 7 columns.

| Column | Description |
|---|---|
| age | Age of the individual |
| sex | Gender |
| bmi | Body Mass Index |
| children | Number of dependents |
| smoker | Smoking status |
| region | Residential region |
| charges | Medical insurance cost |

**Target variable:** `charges`
